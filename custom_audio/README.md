# Custom CradleDial recordings

Drop your own voice files in this folder when they are ready. The spoken placeholders already on the server can be replaced one lesson at a time.

Use the same names the phone system expects:

- `hausa/week_16.wav`
- `yoruba/week_20.wav`
- `english/week_16.wav`
- `pidgin/week_16.wav`
- `igbo/week_16.wav`
- `emergency/ward4_cholera.wav`

`.wav`, `.mp3`, and `.m4a` are all fine. After a file is in this folder, ask for it to be converted to an 8kHz, 16-bit, mono `.wav` and uploaded to the CradleDial audio bucket. The public link for each lesson stays the same, so the dashboard and the phone calls pick up the new recording without any other change.
